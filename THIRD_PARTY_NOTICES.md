# Third-party notices

MycoDemo reuses or considered the sources below. This file records what was taken,
where it lives in our code, what was changed, and what was looked at but not used.
Update it whenever a source is added or dropped.

## Used

### mycro-grow (MIT)

- Source: https://github.com/SaschaHeyer/mycro-grow
- Version read: commit `7cb8de13b602035f9bcc7eecb4b5d421b9de76a6` (cloned 2026-10-11)
- Licence: MIT, Copyright (c) 2026 Mycro (https://usemycro.com). Full text below.
- What we took: the grow maths and reference data, **ported to Python** (no JavaScript is shipped).
- Taken on 2026-10-11 (project owner's go-ahead for these files).

| Original file | Our file | What it holds |
|---|---|---|
| `src/grow.js` | `mycodemo/cultivation/calculations.py` | hydration, spawn, yield from biological efficiency, economics, batch plan |
| `src/substrate.js` | `mycodemo/cultivation/recipes.py` | four recipe presets and the recipe calculation |
| `src/data.js` | `mycodemo/cultivation/species.py` | 9 BE presets, 14-species fruiting conditions (copied programmatically, not retyped) |
| `test/grow.test.js` | `tests/test_cultivation_parity.py` | the 12 original tests, plus reference values generated by running the original code |

Changes from the original: **none in behaviour.** Only renaming (camelCase to
snake_case, for example `growPlan` to `grow_plan`, `costPerBlock` to `cost_per_block`)
and Python syntax. Known limits of the original that we keep for now and will handle
in a separate module are listed in `docs/docs/cultivation-port.md`.

Not taken: `bin/cli.js`, `examples/season-plan.js`, `docs/`, `README.md`.
